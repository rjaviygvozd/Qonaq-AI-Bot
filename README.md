# Qonaq AI Bot

Школьный Telegram-проект: туристический помощник по Павлодару и Баянаулу.
Текущая версия, как и исходный код, отвечает по ключевым словам; внешняя нейросеть
не подключена. RAG и база из 50 объектов, заявленные в презентации, в переданных
файлах не реализованы. Показатели точности, стоимости и скорости из презентации
не подтверждены переданными тестами или данными.
Непроверенные цены и адреса из прежнего кода убраны.

## Восстановление после опубликованного токена

1. Откройте официальный @BotFather в Telegram.
2. Отправьте `/revoke` и выберите `@qonaq_pavl_tour_bot`. Если новый токен
   не появился, получите его через `/token` или меню API Token.
3. В Render откройте сервис Qonaq-AI-Bot → Environment → Add/Edit Environment Variables.
4. Создайте `BOT_TOKEN` и вставьте **новый** токен только туда.
   Не добавляйте его в GitHub, переписку или скриншоты.
5. Нажмите Save, rebuild, and deploy. Дождитесь Live.
6. Откройте `/health` на адресе сервиса: ожидается `ready: true`.
7. В Telegram отправьте `/start` один раз. Должно прийти одно приветствие с кнопками.

Публикация токена позволяет посторонним управлять ботом, даже если код правильный.
Удаление токена из текущего файла не удаляет его из старых коммитов.
В исходном файле и прежней версии Render оказались два разных бота:
`@Qonaq_Pavlodar_bot` и `@qonaq_pavl_tour_bot`. Оба токена опубликованы в истории
GitHub, оба нужно отозвать. Код отвергает отпечатки обоих старых токенов.
Исправленный сервис настроен на созданный владельцем аккаунта `@qonaq_pavl_tour_bot`.
Бот из школьного исходника `@Qonaq_Pavlodar_bot` принадлежит отдельному аккаунту;
его опубликованный токен должен отозвать его владелец.
Старые рекламные сообщения останутся в истории чата; их можно удалить вручную.
Чужую аватарку замените через @BotFather → `/setuserpic`.
Название, описание и команды восстанавливаются независимо друг от друга при запуске.
Временный лимит Telegram (429) обрабатывается с указанной Telegram задержкой.
Если Telegram запрещает изменение имени (400), поменяйте его через BotFather → `/setname`.
При восстановлении чужого рекламного названия его аватарка также удаляется.

## Настройки существующего Render Web Service

Используется уже созданный сервис, без смены тарифа:

| Настройка | Значение |
| --- | --- |
| Branch | main |
| Build Command | pip install -r requirements.txt |
| Start Command | python bot.py --port 10000 |
| BOT_TOKEN | Новый токен из BotFather |
| WEBHOOK_URL | HTTPS-адрес сервиса, без /telegram |
| WEBHOOK_SECRET | Случайный секрет длиной 32–256 символов A–Z, a–z, 0–9, _ или - |
| EXPECTED_BOT_USERNAME | qonaq_pavl_tour_bot |

`WEBHOOK_URL` можно не задавать: тогда используется `RENDER_EXTERNAL_URL`.
Порт берётся из `PORT`, а при его отсутствии — из `--port`.
Секрет генерируется командой `python -c "import secrets; print(secrets.token_urlsafe(32))"`.
`BOT_TOKEN` и `WEBHOOK_SECRET` храните только в настройках сервиса.

В проекте нет polling и фоновой рассылки. Telegram отправляет запросы на `/telegram`.
Запросы проверяются по секретному заголовку. Бот отвечает только на текст человека
в личном чате; закрепления, редактирования, фотографии и сообщения ботов игнорируются.
SQLite хранит только ID обновлений в течение двух суток и предотвращает повторные ответы.

`/` показывает, что веб-сервер запущен. `/health` возвращает 200 только после
успешной настройки Telegram. При отсутствии токена сервер ожидает настройки и
сообщения не отправляет. При ошибке настройки проверьте Environment и перезапустите сервис.

## Проверка

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Тесты используют подставной Telegram API и не отправляют настоящие сообщения.
Проверьте в Telegram: `/start`, три кнопки, неизвестный вопрос, `/help`, `/about`.
Открытие страницы сервиса или чата само по себе ничего не рассылает.

## Ограничения школьной версии

Render Free может засыпать после 15 минут без входящих запросов. Webhook позволяет
сообщению разбудить сервис; первый ответ после простоя может задержаться примерно на минуту.
Не запускайте старую копию бота с новым токеном на другом сервере одновременно.

На бесплатном Render локальная SQLite очищается при перезапуске/развёртывании/сне.
Защита от повторов действует, пока сохранена база; абсолютную гарантию единственного
ответа через перезапуски даёт только внешнее постоянное хранилище.
При сетевом тайм-ауте отправка не повторяется автоматически: ответ мог уже дойти.
В редком случае пользователь получит ответ только после нового вопроса.
При ошибке 429 запрос может быть повторён, поскольку Telegram отклонил отправку.
